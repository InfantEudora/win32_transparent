# Chasm wiki

What is in the game, how it works, and where it is going: a page for each thing the player meets.

A page says what the game does **today**, briefly, and links to everything it touches, so following the
links shows how the mechanics hang together. The reasons and the history are in the plans
(`apps/chasm/docs/`). Each page names the plan sections it came from and the code it was checked against.

Figures with a dotted underline are read from the code every time the wiki is built. Hover over one to see
its constant. Links in red are pages that haven't been written yet.

So far the pages cover the woodcutter's loop and the needs and homes around it. The rest gets written
as features are worked on.
